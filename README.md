# CourseHub - MVP платформы для онлайн-курсов

Современная платформа для создания и изучения онлайн-курсов с cohort-first подходом.

## 🚀 Быстрый старт

```bash
# Клонирование и установка зависимостей
git clone <repository-url>
cd course-platform
npm install

# Запуск в режиме разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🚀 Новые возможности (Спринт 1)

### ⚡ Quick Create - Быстрое создание курса
- **Drag & Drop загрузка файлов** - просто перетащите видео, аудио, PDF
- **Автоматическая генерация структуры** - система создает уроки из файлов
- **Умная организация** - автоматическое разбиение на модули
- **Поддержка форматов**: видео (mp4, avi, mov), аудио (mp3, wav), PDF, текст

### 📋 Шаблоны курсов
- **Марафон 14 дней** - интенсивное обучение с ежедневными заданиями
- **Интенсив 7 дней** - быстрое погружение в тему за неделю  
- **Курс 4 недели** - сбалансированное обучение с еженедельными модулями
- **Профессия 8 недель** - комплексное обучение с портфолио
- **Свой формат** - создание с нуля по индивидуальному плану

### 👁️ Предпросмотр как студент
- **Одна кнопка** в редакторе курса открывает вид студента
- **Мгновенная проверка** UX без переключения ролей
- **Тестирование** всех функций обучения

### 🏗️ Улучшенная архитектура
- **Разделенные stores** - auth, courses, progress, chat
- **Версионирование данных** - безопасные обновления localStorage
- **Строгая типизация** - все данные типизированы TypeScript
- **Модульная структура** - легко расширять и поддерживать

## 📋 Основные возможности
- **Дашборд** - статистика курсов, студентов и доходов

- **Видеоплеер** - просмотр уроков с сохранением позиции
- **Материалы** - дополнительные файлы и ссылки
- **Задания** - практические задания к урокам

## 🎯 Как использовать новые возможности

### ⚡ Быстрое создание курса (5-10 минут)
1. Нажмите "Создать курс" в разделе "Мои курсы"
2. Выберите "Быстрое создание"
3. Перетащите файлы курса в область загрузки
4. Заполните основную информацию (название, описание, категория)
5. Нажмите "Создать курс" - структура создастся автоматически!

### 📋 Создание по шаблону (10-15 минут)
1. Выберите "По шаблону" при создании курса
2. Выберите подходящий шаблон (Марафон, Интенсив, Курс, Профессия)
3. Заполните информацию о курсе
4. Получите готовую структуру с модулями и уроками

### 👁️ Предпросмотр курса
- В редакторе курса нажмите "Смотреть как студент"
- Откроется новая вкладка с видом студента
- Протестируйте все функции обучения

### 🔄 Переключение ролей
- На главной странице выберите нужную роль
- В боковом меню нажмите "Сменить роль"
- Роль сохраняется автоматически

На главной странице выберите роль:
- **Я Автор** - для создания и продажи курсов
- **Я Покупатель** - для изучения курсов

Роль сохраняется в localStorage. Для смены роли вернитесь на главную страницу или нажмите "Сменить роль" в боковом меню.

## 🛠 Технологический стек

- **Frontend**: Next.js 16 + TypeScript
- **Стили**: TailwindCSS 4
- **Состояние**: Zustand с persist middleware
- **Видеоплеер**: Кастомный компонент с HTML5 video
- **Данные**: Mock данные (без БД для MVP)
- **Иконки**: Emoji (для простоты MVP)

## 🎮 Основные функции

### 🎬 Видеоплеер
- **Горячие клавиши**: 
  - `Пробел` - play/pause
  - `←/→` - перемотка ±10 сек
- **Скорость воспроизведения**: 0.75x - 2x
- **Автосохранение позиции** просмотра в localStorage
- **Навигация между уроками** с кнопками "Предыдущий/Следующий"

### 📊 Система прогресса
- Отслеживание завершенных уроков
- Визуальные индикаторы прогресса (зеленые точки)
- Процент завершения курса
- Сохранение в localStorage

### 💬 Чат в потоках
- Групповое общение автора и студентов
- Сохранение сообщений в памяти (для MVP)
- Простой UI мессенджера
- Отправка сообщений по Enter

### 🛒 Система покупок (MVP)
- Эмуляция покупки курса (без реальных платежей)
- Добавление в "Мои курсы" через localStorage
- Отслеживание купленных курсов

## 🔧 Настройка и расширение

### Добавление новых курсов
Отредактируйте `src/lib/mockData.ts` и добавьте новые объекты в массив `mockCourses`:

```typescript
{
  id: 'new-course-id',
  title: 'Название курса',
  description: 'Описание курса',
  // ... остальные поля
}
```

### Изменение текстов
Все тексты интерфейса находятся в `src/lib/strings.ru.ts`:

```typescript
export const strings = {
  courseTitle: 'Название курса',
  // ... добавьте новые строки
};
```

### Стилизация
Используется TailwindCSS 4. Кастомные компоненты в `src/components/ui/`.

Пример кастомизации:
```tsx
<Button variant="primary" size="lg" className="custom-class">
  Текст кнопки
</Button>
```

## 🚧 Ограничения MVP

- ❌ Нет реальной авторизации (роли в localStorage)
- ❌ Нет базы данных (mock данные)
- ❌ Нет реальных платежей (эмуляция покупки)
- ❌ Нет загрузки файлов (заглушки)
- ❌ Чат только в памяти браузера
- ❌ Нет push-уведомлений
- ❌ Нет email-рассылок
