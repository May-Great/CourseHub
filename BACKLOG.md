# 📋 Product Backlog - CourseHub

## 🔥 Спринт 2: Cohort-механики (Следующий)

**Цель**: Повысить completion rate с 20% до 60%+
**Длительность**: 2 недели
**Приоритет**: Высокий

### 📝 User Stories

#### Epic 1: Дедлайны и прогресс
- **US-001**: Как автор, я хочу устанавливать дедлайны для уроков, чтобы студенты не откладывали обучение
- **US-002**: Как студент, я хочу видеть дедлайны в календаре, чтобы планировать время
- **US-003**: Как автор, я хочу видеть прогресс всей группы, чтобы понимать темп обучения

#### Epic 2: Система заданий
- **US-004**: Как автор, я хочу создавать задания к урокам, чтобы проверять понимание
- **US-005**: Как студент, я хочу сдавать задания и получать обратную связь
- **US-006**: Как автор, я хочу проверять задания и оставлять комментарии

#### Epic 3: Чекпоинты и вовлечение
- **US-007**: Как автор, я хочу проводить еженедельные чекпоинты, чтобы поддерживать мотивацию
- **US-008**: Как студент, я хочу делиться успехами и трудностями с группой
- **US-009**: Как студент, я хочу получать бейджи за достижения, чтобы чувствовать прогресс

### 🛠️ Технические задачи

1. **T-001**: Добавить поле deadline в Lesson type
2. **T-002**: Создать компонент DeadlineCalendar
3. **T-003**: Добавить визуальные индикаторы просроченных дедлайнов
4. **T-004**: Реализовать уведомления о приближающихся дедлайнах

#### Задача 2: Система заданий (4 дня)
1. **T-005**: Расширить Assignment type (статусы, файлы, оценки)
2. **T-006**: Создать компонент AssignmentSubmission
3. **T-007**: Создать компонент AssignmentReview для авторов
4. **T-008**: Добавить файловые вложения к заданиям

#### Задача 3: Прогресс группы (2 дня)
1. **T-009**: Создать компонент GroupProgress
2. **T-010**: Добавить агрегацию данных по группе
3. **T-011**: Визуализация прогресса (графики, диаграммы)

#### Задача 4: Чекпоинты (3 дня)
1. **T-012**: Создать тип CheckpointForm
2. **T-013**: Компонент еженедельной формы обратной связи
3. **T-014**: Лента чекпоинтов в чате группы
4. **T-015**: Аналитика по чекпоинтам для автора

#### Задача 5: Бейджи и достижения (2 дня)
1. **T-016**: Создать систему Achievement
2. **T-017**: Компонент BadgeCollection
3. **T-018**: Логика начисления бейджей
4. **T-019**: Уведомления о получении бейджей

### 📊 Definition of Done

### 🎯 Критерии успеха

## 🚨 Риски и митигация

### Риск 1: Сложность для пользователей
**Митигация**: Пошаговые туториалы, умные дефолты, прогрессивное раскрытие функций

### Риск 2: Производительность с большим количеством данных
**Митигация**: Виртуализация списков, ленивая загрузка, оптимизация re-renders

### Риск 3: Низкое принятие новых функций
**Митигация**: A/B тестирование, сбор обратной связи, итеративные улучшения
