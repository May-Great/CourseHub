# Настройка Базы Данных Supabase

Для того чтобы приложение начало сохранять данные в облаке, нужно выполнить следующие шаги:

## 1. Создание проекта
1. Зайдите на [supabase.com](https://supabase.com) и зарегистрируйтесь/войдите.
2. Нажмите **"New Project"**.
3. Заполните данные:
   - **Name:** CourseHub (или любое другое)
   - **Database Password:** Придумайте сложный пароль и сохраните его.
   - **Region:** Выберите ближайший (например, Frankfurt).

## 2. Получение ключей API
1. После создания проекта перейдите в **Project Settings** (шестеренка внизу слева) -> **API**.
2. Скопируйте `Project URL`.
3. Скопируйте `anon` / `public` key.
4. Откройте файл `.env.local` в вашем проекте и вставьте данные:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=ваш_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_ключ
   ```

## 3. Создание таблиц (Schema)
1. В панели Supabase перейдите в **SQL Editor** (иконка консоли слева).
2. Нажмите **"New Query"**.
3. Откройте файл `supabase/schema.sql` из этого проекта.
4. Скопируйте всё его содержимое и вставьте в SQL Editor на сайте.
5. Нажмите кнопку **Run** (зеленая кнопка справа внизу).

🎉 **Готово!** Теперь у вас созданы все необходимые таблицы и настроена безопасность.

## 4. Проверка
1. Запустите проект: `npm run dev`
2. Зарегистрируйтесь как новый пользователь.
3. Попробуйте создать курс (пока интерфейс может быть не полностью подключен к базе, но вход уже будет работать через базу).
