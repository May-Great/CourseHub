# Архитектура и Технологии CourseHub

## 1. Технологический стек

### Core (Ядро)
- **Framework:** [Next.js 16 (App Router)](https://nextjs.org) — Современный React-фреймворк для SSR и статики.
- **Language:** TypeScript 5 — Строгая типизация для надежности кода.
- **State Management:** Zustand — Легковесное управление состоянием (auth, notifications, cart).

### UI/UX
- **Styling:** Tailwind CSS v4 — Утилитарный CSS для быстрой верстки.
- **Components:** Radix UI (Headless) + Lucide Icons — Доступные и красивые компоненты.
- **Animation:** `tailwindcss-animate` — Плавные переходы и анимации интерфейса.

### Backend & Data
- **Database:** Supabase (PostgreSQL) — Реляционная база данных с Row Level Security (RLS).
- **Auth:** Supabase Auth — Управление пользователями, вход по Email/Password и Magic Link.
- **Storage:** Supabase Storage — Хранение видео и изображений (в планах).

### Testing
- **Unit Tests:** Vitest + React Testing Library — Быстрое тестирование компонентов и логики.

## 2. Как работает Регистрация и Хранение данных

### Текущее состояние (Mock Mode vs Production)

В данный момент проект поддерживает **два режима работы**, что позволяет разрабатывать даже без интернета или ключей API.

#### А. Mock Mode (Демо-режим)
*   **Когда работает:** Если в файле `.env.local` нет ключей Supabase.
*   **Где хранятся данные:** В `localStorage` браузера пользователя.
*   **Ограничения:** Данные исчезают, если очистить кэш браузера или зайти с другого устройства. Регистрация "фейковая" (просто сохраняет пользователя в память браузера).
*   **Тестовые аккаунты:**
    *   Автор: `adminIMN1` / `adminIMN1`
    *   Студент: `adminIMN2` / `adminIMN2`

#### Б. Production Mode (Реальный режим)
*   **Когда работает:** Когда добавлены `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
*   **Где хранятся данные:** В облачной базе данных PostgreSQL (Supabase).
*   **Безопасность:**
    *   Пароли хешируются (bcrypt).
    *   Доступ к данным защищен политиками RLS (никто не может прочитать чужие данные).
    *   Сессии управляются через безопасные HttpOnly Cookies.

### Статус регистрации
С регистрацией **все хорошо**. Мы реализовали гибридную систему:
1.  Форма входа/регистрации (`/login`) полностью готова.
2.  Она автоматически определяет, подключена ли база данных.
3.  Если база есть — создает реального пользователя.
4.  Если базы нет — эмулирует вход, чтобы вы могли тестировать интерфейс.
